# Котигорошко — інтерактивна книга

Лабораторна робота №2. Вебсторінка-книга за українською народною казкою «Котигорошко»: обкладинка та 12 сторінок з ілюстраціями, перемикання сторінок кнопками «Попередня» / «Далі» та стрілками клавіатури, декоративний ініціал на першій сторінці.

**Виконав:** Кліщ Юрій, група ІА-401 (klishchyuriy)

## Структура
- `index.html` — обкладинка
- `1.html` … `12.html` — сторінки казки
- `style.css` — оформлення (ініціал: `.initial::first-letter`)
- `script.js` — анімація перегортання та керування стрілками
- `img/` — ілюстрації
- `fonts/` — шрифти Ruslan Display та Cormorant Garamond (SIL Open Font License)

Текст казки — власний переказ народного твору.
